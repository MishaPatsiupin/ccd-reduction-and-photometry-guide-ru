# Руководство по обработке CCD данных и звёздной фотометрии с использованием astropy и связанных пакетов

**Русская версия** | [English version (original)](https://github.com/astropy/ccd-reduction-and-photometry-guide)

Это русский перевод руководства по обработке CCD данных и фотометрии.

Вдохновением для этой работы послужили два руководства и книга:

+ [A User's Guide to Stellar CCD Photometry with IRAF](https://www.mn.uio.no/astro/english/services/it/help/visualization/iraf/daophot2.pdf) Massey and Davis (1992)
+ [A User's Guide to CCD Reductions with IRAF](http://ircamera.as.arizona.edu/Astr_518/irafguid.pdf) Massey (1997)

## 🔧 Сборка локально

Чтобы собрать книгу локально:

```bash
# Клонировать репозиторий
git clone https://github.com/MishaPatsiupin/ccd-reduction-and-photometry-guide-ru.git
cd ccd-reduction-and-photometry-guide-ru

# Установить зависимости
pip install -r requirements.txt

# Собрать книгу
jupyter-book build .

# Открыть в браузере
# Файл будет в _build/html/index.html
```
