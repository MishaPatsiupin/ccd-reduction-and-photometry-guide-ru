Предисловие#

Цель этого текста — провести вас через процессы обработки изображений и фотометрии с использованием Python, особенно Astropy и связанных пакетов. Предполагается базовое знакомство с астрономическими изображениями и Python. Вдохновением для этой работы послужила пара руководств, написанных для IRAF: “Руководство пользователя по обработке CCD с помощью IRAF” (Massey 1997) и “Руководство пользователя по звёздной фотометрии CCD с помощью IRAF” (Massey and Davis 1992).

Фокус сделан на оптических/ИК изображениях, а не на спектрах.

Номера изданий#

Руководство теперь имеет номера версий, примерно эквивалентные изданиям печатной книги. Каждый номер состоит из трёх частей — например, первая официальная стабильная версия 2.0.0. Думайте об этом как о примерном эквиваленте «издания», «ревизии» и «тиража» в мире физических книг.

Номер издания указан на боковой панели.

Вот что означают изменения в каждом из этих номеров:

  • Изменение первого номера, например 2.0.0 → 3.0.0, указывает на крупную ревизию, которая изменяет нумерацию разделов или добавляет значительные новые разделы.

  • Изменение среднего номера, например 2.0.0 → 2.1.0, указывает на существенные обновления содержимого и/или исправление важных ошибок. Номера разделов при этом не изменятся.

  • Изменение последнего номера, например 2.0.0 → 2.0.1, указывает на незначительные изменения, такие как исправление опечаток, неработающих ссылок и подобных корректировок. Номера разделов в этих ревизиях не изменятся.

Кроме того, доступна «разрабатываемая» версия, отражающая последние изменения, внесённые в руководство между релизами.

Те, кто знаком с семантическим версионированием из разработки ПО, узнают в этом примерно эквивалент для текста.

Ресурсы#

Эта астрономическая работа была вдохновлена и руководствовалась превосходными ресурсами ниже:

  • “Руководство пользователя по обработке CCD с помощью IRAF” (Massey 1997) очень подробное, но IRAF стал более сложным для установки со временем и больше не поддерживается.

  • “Руководство пользователя по звёздной фотометрии CCD с помощью IRAF” (Massey and Davis 1992).

  • Справочник по обработке астрономических изображений Richard Berry и James Burnell. Это предоставляет очень детальный обзор обработки данных и фотометрии. Одним из достоинств является включение реальных изображений с дефектами.

  • Руководство по CCD наблюдениям AAVSO предоставляет полное введение в обработку CCD данных и фотометрию.

  • Руководство для начинающих по работе с астрономическими данными намного шире, чем это руководство. Оно включает введение в Python.

Настройка программного обеспечения/начало работы на вашем компьютере#

Настройка Python#

Для использования любого из этого программного обеспечения вам понадобится установка Python. Мы рекомендуем инсталлятор mambaforge или инсталлятор miniconda (или гораздо больший дистрибутив Anaconda Python если необходимо). После установки вы можете установить всё необходимое командой:

conda install -c astropy ccdproc photutils ipywidgets matplotlib jupyterlab

(в качестве альтернативы, mamba должна работать вместо conda; если вы получите сообщение об ошибке, что нужно инициализировать mamba, то следуйте инструкциям в этом сообщении.

Получение копии этих ноутбуков#

Получите копию этих файлов с https://github.com/astropy/ccd-reduction-and-photometry-guide – нажмите на зелёную кнопку “Code” и либо клонируйте (если вы используете git), либо скачайте zip файл и извлеките его. Если вы ищете конкретное издание, например 2.0.0, то перейдите на https://github.com/astropy/ccd-reduction-and-photometry-guide/releases.

Если вы хотите запустить этот код в ноутбуке из командной строки#

Откройте терминал, перейдите в папку notebooks в этом репозитории, введите jupyter lab, и должна открыться вкладка браузера с ноутбуками.

Вам всё равно нужно будет скачать данные, следуя инструкциям ниже в разделе Файлы данных

Если вы хотите запустить этот код каким-то другим способом (IPython, Spyder, Visual Studio Code, …)#

Spyder и Visual Studio Code могут запускать ноутбуки; следуйте инструкциям выше чтобы получить ноутбуки. Следуйте инструкциям для открытия ноутбуков в выбранном вами инструменте.

Если вы копируете/вставляете код из онлайн-книги в один из этих инструментов, вам нужны два файла из репозитория. Следуйте инструкциям по получению копии репозитория, затем скопируйте два файла download_data.py и convenience_functions.py из папки notebooks в папку, в которой вы планируете запускать код.

Вам всё равно нужно будет скачать данные, следуя инструкциям ниже в разделе Файлы данных
