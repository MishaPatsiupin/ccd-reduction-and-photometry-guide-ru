1.8. Чтение изображений#

Astropy предоставляет несколько способов чтения FITS изображений, некоторые в основном пакете, а другие в аффилированных пакетах.

Прежде чем изучить их, мы создадим набор (фальшивых) изображений для работы.

from pathlib import Path
from astropy.nddata import CCDData
from astropy.io import fits

1.8.1. Работа с директориями#

Ячейка ниже содержит путь к изображениям. В этом notebook мы будем использовать его как для сохранения созданных фальшивых изображений, так и для чтения изображений. При обычном использовании вы не начинали бы с записи изображений туда.

Если изображения находятся в той же директории, что и notebook, вы можете опустить это или установить пустую строку ''. Хранение изображений в той же директории, что и notebook, менее сложно, но довольно часто требуется работать с изображениями в другой директории.

Позже мы рассмотрим, как сформировать полный путь к изображению (директория плюс имя файла) способом, который будет работать на любой платформе. Один из подходов к загрузке изображений (используя ccdproc.ImageFileCollection) позволяет в основном забыть об этом.

data_directory = 'path/to/my/images'

1.8.2. Генерация фальшивых изображений#

Ячейки ниже генерируют несколько фальшивых изображений для использования далее в notebook.

from pathlib import Path
from itertools import cycle

import numpy as np

image_path = Path(data_directory)

image_path.mkdir(parents=True, exist_ok=True)

images_to_generate = {
    'BIAS': 5,
    'DARK': 10,
    'FLAT': 3,
    'LIGHT': 10
}

exposure_times = {
    'BIAS': [0.0],
    'DARK': [5.0, 30.0],
    'FLAT': [5.0, 6.1, 7.3],
    'LIGHT': [30.0],
}

filters = {
    'FLAT': 'V',
    'LIGHT': 'V'
}

objects = {
    'LIGHT': ['m82', 'xx cyg']
}

image_size = [300, 200]

image_number = 0
for image_type, num in images_to_generate.items():
    exposures = cycle(exposure_times[image_type])
    try:
        filts = cycle(filters[image_type])
    except KeyError:
        filts = []
    
    try:
        objs = cycle(objects[image_type])
    except KeyError:
        objs = []
    for _ in range(num):
        img = CCDData(data=np.random.randn(*image_size), unit='adu')
        img.meta['IMAGETYP'] = image_type
        img.meta['EXPOSURE'] = next(exposures)
        if filts:
            img.meta['FILTER'] = next(filts)
        if objs:
            img.meta['OBJECT'] = next(objs)
        image_name = str(image_path / f'img-{image_number:04d}.fits')
        img.write(image_name)
        print(image_name)
        image_number += 1

1.8.3. Вариант 1: Чтение одного изображения с помощью astropy.io.fits#

Этот вариант дает вам максимальную гибкость, но наименее адаптирован конкретно к CCD изображениям. То, что вы читаете, это список FITS расширений; сначала вы должны выбрать нужное, затем получить доступ к данным или заголовку по желанию.

Мы откроем первое из фальшивых изображений, img-0001.fits. Чтобы объединить его с именем директории, мы используем pathlib из Python 3, который гарантирует, что комбинация путей будет работать и в Windows.

image_name = 'img-0001.fits'

image_path = Path(data_directory) / image_name

hdu_list = fits.open(image_path)
hdu_list.info()

1.8.4. Вариант 2: Использование CCDData для чтения одного изображения#

Astropy содержит объект CCDData для представления одного изображения. Он не так гибок, как прямое использование astropy.io.fits (например, он предполагает, что есть только одно FITS расширение и что оно содержит данные изображения), но он настраивает несколько свойств, которые облегчают работу с данными.

Мы прочитаем то же самое изображение, что и в примере выше, img-0001.fits.

ccd = CCDData.read(image_path)

К данным и заголовку осуществляется доступ аналогично тому, как вы обращаетесь к ним в HDU, возвращаемом astropy.io.fits:

1.8.5. Вариант 3: Работа с директорией изображений используя ImageFileCollection#

Аффилированный пакет ccdproc предоставляет более простой способ работы с коллекциями изображений в директории: ImageFileCollection. ImageFileCollection инициализируется именем директории, содержащей изображения.

from ccdproc import ImageFileCollection
im_collection = ImageFileCollection(data_directory)

Обратите внимание, что нам не нужно беспокоиться об использовании pathlib для объединения директории и имени файла, вместо этого мы передаем коллекции имя директории.

1.8.5.2. Фильтрация и итерация по изображениям#

Замечательная особенность ImageFileCollection в том, что он предоставляет удобные способы фильтрации или перебора файлов по значениям FITS заголовков.

Например, перебор только файлов flat это одна строка кода:

for a_flat in im_collection.hdus(imagetyp='FLAT'):
    print(a_flat.header['EXPOSURE'])

5.0
6.1
7.3

Вместо итерации по HDU, как в примере выше, вы можете итерировать только по заголовкам (с .headers) или только по данным (с .data). Вы можете использовать любое FITS ключевое слово из заголовка как ключевое слово для выбора нужных изображений. Кроме того, вы можете возвращать имя файла вместе с итерацией.

for a_flat, fname in im_collection.hdus(imagetyp='LIGHT', object='m82', return_fname=True):
    print(f'In file {fname} the exposure is:', a_flat.header['EXPOSURE'], 'with standard deviation ', a_flat.data.std())
