# Инструкция по созданию релизов

## Автоматический релиз через GitHub Actions

### Способ 1: Создание тега (рекомендуется)

1. Создайте и запушьте тег версии:
```bash
git tag -a v1.0.0 -m "Первый релиз русской версии"
git push origin v1.0.0
```

2. GitHub Actions автоматически:
   - Соберёт книгу
   - Создаст архивы (ZIP и TAR.GZ)
   - Создаст релиз с описанием
   - Прикрепит файлы к релизу

### Способ 2: Ручной запуск workflow

1. Перейдите в репозиторий на GitHub
2. Откройте вкладку **Actions**
3. Выберите **Создание релиза** в списке слева
4. Нажмите **Run workflow**
5. Введите версию (например, `v1.0.0`)
6. Нажмите **Run workflow**

## Ручное создание релиза на GitHub

Если вы хотите создать релиз вручную:

1. Соберите книгу локально:
```bash
cd d:\astro\ccd-reduction-and-photometry-guide
jupyter-book build .
```

2. Создайте архивы:
```powershell
# ZIP архив
Compress-Archive -Path _build\html\* -DestinationPath ccd-guide-russian.zip

# Или используйте 7-Zip, если установлен
7z a -tzip ccd-guide-russian.zip .\_build\html\*
```

3. На GitHub:
   - Перейдите в раздел **Releases**
   - Нажмите **Draft a new release**
   - Выберите или создайте тег (например, `v1.0.0`)
   - Заполните название и описание
   - Прикрепите архив
   - Нажмите **Publish release**

## Настройка GitHub Pages

Чтобы книга автоматически публиковалась на GitHub Pages:

1. Перейдите в **Settings** вашего репозитория
2. Откройте **Pages** в левом меню
3. В разделе **Source** выберите:
   - **Source**: Deploy from a branch
   - **Branch**: `gh-pages`
   - **Folder**: `/ (root)`
4. Нажмите **Save**

После следующего push в main, книга будет доступна по адресу:
`https://MishaPatsiupin.github.io/ccd-reduction-and-photometry-guide-ru/`

## Версионирование

Рекомендуемая схема версий (Semantic Versioning):

- **v1.0.0** - Первый полный перевод
- **v1.1.0** - Добавлены новые переводы или улучшения
- **v1.0.1** - Исправление ошибок в переводе
- **v2.0.0** - Крупные изменения структуры
