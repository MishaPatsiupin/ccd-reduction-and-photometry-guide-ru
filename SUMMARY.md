## 🚀 Как использовать

### Автоматическая публикация на GitHub Pages

Просто сделайте коммит и push в ветку `main`:
```bash
git add .
git commit -m "Обновление контента"
git push origin main
```

Результат будет доступен по адресу:
**https://MishaPatsiupin.github.io/ccd-reduction-and-photometry-guide-ru/v/dev/**

### Создание релиза

#### Способ 1: Через создание тега (рекомендуется)
```bash
git tag -a v1.0.0 -m "Первый релиз русской версии"
git push origin v1.0.0
```

Это автоматически:
1. Запустит workflow сборки и публикации (ci_tests.yml)
2. Опубликует на GitHub Pages в `v/v1.0.0/`
3. Запустит workflow создания релиза (release.yml)
4. Создаст GitHub Release с архивами

#### Способ 2: Через GitHub UI
1. Перейдите в **Actions**
2. Выберите **Создание релиза**
3. Нажмите **Run workflow**
4. Введите версию (например, `v1.0.0`)
5. Нажмите **Run workflow**

### Ручная публикация

Для экстренных случаев или тестирования:
1. Перейдите в **Actions**
2. Выберите **Сборка и публикация Jupyter Book (ручной запуск)**
3. Нажмите **Run workflow**
